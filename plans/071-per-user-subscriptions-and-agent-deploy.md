# 071 用户独立的节点与订阅、面板经节点端部署

## 背景（用户反馈）

- 部署节点只有管理员可用；代理节点、订阅管理、生成订阅、订阅下载每个用户都能用，数据各自独立、不能共享。
- 每个页面左上方加文字说明。
- 代理节点：标签 / 来源下拉框各出现两个「全部」；需要按隧道筛选；勾选后的批量操作栏位置歪。
- 部署节点：要完全由面板部署管理（像管理隧道转发那样），不是用户自己在服务器上运行脚本；可多选 FLVX 节点同时部署；部署后的参数可复制到其他服务器部署。
- 生成订阅：不分配给用户；生成的配置无法访问「IP+端口」的网站；选择节点的标签筛选也有重复「全部标签」。

## 设计

### 用户独立
- `proxy_node`、`sub_file` 增加 `user_id`，所有接口按当前登录用户过滤（管理员也只看自己的）。
- 旧数据（`user_id = 0`）在启动时归属第一个管理员；导入备份时缺少或指向不存在用户的数据同样归属管理员。
- 删除用户时一并删除其代理节点和订阅。
- 订阅不再分配给用户：去掉 `sub_file_user` 的使用、分配接口和界面；订阅下载只列自己的订阅。备份结构保留 `userIds` 字段（忽略），兼容 2.2.1 的备份。
- 隧道中转沿用转发接口（以当前用户身份创建 / 更新 / 删除转发），关联已有转发只列当前用户自己的转发；隧道列表用 `/tunnel/user/tunnel`（普通用户只看到有权限的隧道）。
- 权限：`/api/v1/proxy-node/*`、`/api/v1/subscription/*` 所有登录用户可用，`/api/v1/deploy/*` 仅管理员。

### 面板经节点端部署（不再用 SSH / 手动粘贴）
- 节点端（go-gost）新增 `MihomoScript` 命令：
  - `start`：下载 mihomo_script（只允许 https）到临时文件，用 `bash` 执行 `install/info/status/restart/uninstall`，参数逐个校验（命令白名单、选项白名单、值只允许安全字符），异步运行，返回任务 ID。
  - `poll`：按偏移返回增量日志、状态和退出码；`install/info` 成功后附带 `/etc/mihomo/share.txt`。
  - 同一时间只运行一个任务；20 分钟超时；日志保留末尾 256KB；完成的任务保留 1 小时。
- 面板：
  - 一条部署记录 = 一个 FLVX 节点 + 一组参数；新建时可多选节点（同一组参数，各自使用节点地址），也可把已有记录的参数复制到其他节点。
  - 部署 / 刷新状态（info）/ 卸载：下发命令后后台轮询，实时保存日志；成功后解析分享链接生成或更新代理节点（归属创建部署的管理员）。
  - 记录任务 ID，面板重启后继续轮询；节点端不支持该命令时提示升级节点端。
  - 保留「复制安装命令」用于未接入面板的服务器；去掉 SSH 部署和粘贴输出。

### 生成订阅：IP+端口网站无法访问
- 用户补充：同一个节点用妙妙屋生成的订阅可以正常访问，所以不是服务端问题（最初怀疑的「禁止访问本机和内网」被排除，不加直连规则）。
- 对比妙妙屋的模板：对 IP 目标的分流规则与代理组结构等价，节点字段与 mihomo_script 一致；差别在通用设置——本项目额外开启了 sniffer（默认改写连接目标）、`tcp-concurrent`、`global-client-fingerprint`、`find-process-mode`。
- 修复：默认基础配置去掉这些选项，与妙妙屋 / sublink-worker 的默认通用设置一致。
- 部署表单说明「禁止访问本机和内网」的影响。

### 前端
- 菜单：代理节点、订阅管理、生成订阅、订阅下载对所有用户显示，部署节点仅管理员。
- 新页面统一加左上角标题 + 说明文字。
- 下拉筛选去掉重复的「全部」项（用组件自带的占位选项），代理节点增加隧道筛选，批量操作栏重新排版。
- 部署节点页按新流程重写；订阅 / 生成订阅去掉分配用户。
