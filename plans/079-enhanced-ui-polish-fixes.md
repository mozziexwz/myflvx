# 079 增强功能验收修复

以 `2.2.9`（`36c144ce`）为基线。强化代理节点中转层级，在订阅摘要中提供 IPv4 状态，并收尾旧下载页入口。

## 任务清单

- [x] 核对整改文档、仓库基线和改动范围。
- [x] 增加可见中转计数与归属视觉，保留筛选和拖拽行为。
- [x] 增加订阅摘要的 `ipv4Only` 字段，接入两个视图，并补充契约测试。
- [x] 更新订阅弹窗文案，核对引用后删除旧下载组件。
- [x] 运行后端测试、前端类型检查、生产构建和差异检查。
- [x] 在浏览器验证亮暗主题、窄屏、拖拽与旧下载地址兼容。

## 验证结果

`npx tsc --noEmit`、`npm run build` 和 `git diff --check` 通过。增强功能契约测试及全量契约复跑均通过。新增契约覆盖创建仅 IPv4 订阅后，列表返回 `ipv4Only: true` 并省略配置和正文。

联合运行处理器与契约套件时，28 项处理器用例在 Windows 上因 SQLite 临时文件清理或 Unix 权限断言失败，另有两项限速分发和隧道恢复契约用例间歇失败。全部失败均在原始 `2.2.9` 上复现。

Chromium 用模拟 API 在 320、390 和 1280 像素宽的亮暗模式下检查连续 3px 色条、缩进、可见中转计数、孤立筛选结果和订阅视图。桌面端实测源节点和同组中转的拖拽排序、两个订阅弹窗的文案以及旧下载地址重定向。
