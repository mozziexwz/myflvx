# 073 部署节点：名称跟随节点、每节点一条、卡片样式对齐原版

## 背景（用户反馈）

1. 「名称前缀（可选）」应直接使用节点名称，不用填写，否则卡片会重复显示两个名称。
2. 在线状态改成和原版节点卡片一样：名称后面在线显示绿点、离线显示红点，大小与原版一致。
3. 每个 FLVX 节点只能有一条部署，重复的卡片没有意义也不好管理。
4. 卡片太宽，调整到与原版节点卡片差不多大小。

## 设计

- 名称：部署记录的名称始终等于 FLVX 节点名称（列表实时显示节点当前名称，节点改名后跟着变），新建 / 编辑表单去掉名称输入；代理节点名为「节点名-SS」等。没有关联节点的旧记录继续显示保存的名称。
- 唯一：新建和复制时，已有部署的节点直接拒绝（接口返回错误）；选择节点的列表里这些节点显示「已部署」且不能勾选。已存在的重复记录不自动删除，由用户自行删除。
- 卡片：网格与原版节点页相同（`sm:2 / lg:3 / xl:4 / 2xl:5` 列）；标题行为拖拽手柄 + 节点名 + 状态点（`h-2.5 w-2.5`，在线 `bg-emerald-500`、离线 `bg-rose-500`）+ 部署状态；正文用「标签 — 值」的行展示地址、各协议端口、代理节点数、上次执行；底部按钮改为与原版相同的三列网格。
- 选择节点的列表也使用同样的状态点。
